# ROHANI98 — وب‌سایت فارسی معرفی نرم‌افزار

یک وب‌سایت ایستا و واکنش‌گرا با قالب تیره/سایبری، رنگ‌های نئون آبی، صفحات جداگانه و پشتیبانی از GitHub Pages. **برای راه‌اندازی نیازی به نصب Node.js یا کتابخانه نیست.**

## ۱. مشاهده در کامپیوتر

پوشه پروژه را از فایل ZIP خارج کنید و روی `index.html` دوبار کلیک کنید. برای نمایش کامل‌تر، می‌توانید از افزونه **Live Server** در VS Code استفاده کنید.

## ۲. انتشار در GitHub Pages

1. در GitHub وارد حساب موردنظرتان شوید. اگر سایت را تحت حساب جدید می‌خواهید، با همان حساب وارد شوید.
2. روی `+` → `New repository` بزنید و مخزن عمومی به نام `rohani98-site` بسازید.
3. وارد مخزن شوید، `Add file` → `Upload files` را انتخاب کنید.
4. **فایل ZIP را آپلود نکنید.** ابتدا ZIP را Extract کنید؛ سپس فایل‌های `index.html`, `apps.html`, `app.html`, `about.html`, `support.html`, `contact.html`, `privacy.html`, `404.html`, `README-FA.md` و پوشه `assets` را در ریشه مخزن قرار دهید.
5. `Commit changes` را بزنید.
6. `Settings` → `Pages` → `Build and deployment` را باز کنید، Source را `Deploy from a branch` قرار دهید، Branch را `main` و پوشه را `/(root)` بگذارید؛ سپس `Save` کنید.
7. چند دقیقه بعد، آدرس سایت از قسمت `Pages` نشان داده می‌شود. ساختار معمول: `https://USERNAME.github.io/rohani98-site/`.

> در این پروژه همه مسیرها نسبی هستند و برای آدرس مخزن GitHub Pages و دامنه سفارشی کار می‌کنند.

## ۳. چگونه برنامه جدید اضافه کنم؟

فایل `assets/js/apps.js` را باز کنید. داخل آرایه `window.ROHANI_APPS` یک ورودی جدید مانند نمونه زیر قرار دهید:

```javascript
{
  id: "my-new-app", // شناسه انگلیسی، بدون فاصله و تکرار
  name: "My New App",
  platform: "windows", // یا "android"
  category: "ابزار کاربردی",
  icon: "layers", // mic, calendar, play, captions, scan, sparkles, layers
  accent: "cyan", // cyan, violet, amber, rose, blue, emerald
  featured: true, // نمایش در صفحه اصلی
  tagline: "توضیح کوتاه برنامه",
  description: "توضیحات کامل و دقیق درباره برنامه.",
  features: ["قابلیت اول", "قابلیت دوم", "قابلیت سوم"],
  version: "1.0.0",
  size: "25 MB",
  downloadUrl: "", // پس از آپلود فایل رسمی، آدرس HTTPS را درج کنید
  status: "pending"
}
```

**مهم:** بین برنامه‌ها ویرگول لازم است. شناسه‌های `id` باید یکتا باشند. برنامه‌ها به‌طور خودکار در فهرست، جست‌وجو، فیلتر و صفحه جزئیات دیده می‌شوند. اگر `downloadUrl` خالی باشد، دکمه دانلود غیرفعال است.

### فایل EXE یا APK را کجا قرار دهم؟

برای فایل‌های نرم‌افزار، بهتر است از بخش **Releases** همان مخزن یا مخزن مخصوص برنامه استفاده کنید: در GitHub به مخزن مربوط بروید، `Releases` → `Draft a new release`، نسخه و فایل را اضافه کنید و آن را منتشر کنید. سپس لینک مستقیم فایل رسمی را داخل `downloadUrl` قرار دهید. برای برنامه‌های خودتان، پیش از انتشار فایل را آزمایش کنید.

پس از هر تغییر، فایل به‌روز را در GitHub جایگزین و Commit کنید.

## ۴. تنظیم راه ارتباطی

در ابتدای `assets/js/apps.js` این تنظیمات را می‌بینید:

```javascript
window.ROHANI_CONFIG = {
  siteName: "Rohani98",
  contactEmail: "",
  githubUrl: "",
  contactTelegram: "",
  domain: ""
};
```

تنها ایمیل و لینک‌هایی را وارد کنید که واقعاً متعلق به شما هستند. فرم تماس ایستا است: اگر ایمیل تعریف شده باشد برنامه ایمیل بازدیدکننده را باز می‌کند؛ در غیر این صورت، فقط متن پیام را برای کپی آماده می‌کند و **به هیچ سروری نمی‌فرستد**.

## ۵. آدرس اختصاصی `rohani98.com`

آدرس اختصاصی با ساخت حساب GitHub به وجود نمی‌آید و نیازمند خرید دامنه است. بعد از ثبت دامنه:
1. دامنه را از یک ثبت‌کننده معتبر خریداری کنید.
2. در تنظیمات DNS، رکوردهای موردنیاز GitHub Pages را طبق مستندات رسمی GitHub تنظیم کنید.
3. در `Settings` → `Pages` → `Custom domain` دامنه را وارد کنید و بعد از تایید DNS، HTTPS را فعال کنید.

**فعلاً فایل `CNAME` در پروژه نیست** تا پیش از خرید دامنه، انتشار عادی روی GitHub Pages مختل نشود.

## ۶. ساختار پروژه

```
rohani98-site/
├── index.html          صفحه اصلی
├── apps.html           کاتالوگ، فیلتر و جست‌وجو
├── app.html            جزئیات هر برنامه
├── about.html          درباره ما
├── support.html        راهنمای نصب و FAQ
├── contact.html        تماس با ما
├── privacy.html        سیاست اولیه حریم خصوصی
├── 404.html            صفحه یافت نشد
├── assets/
│   ├── css/style.css   طراحی واکنش‌گرا
│   ├── js/apps.js      اطلاعات برنامه‌ها و تنظیمات سایت
│   ├── js/main.js      عملکرد صفحات و جست‌وجو
│   └── images/favicon.svg
└── README-FA.md
```

## ۷. مواردی که پیش از انتشار عمومی باید تکمیل کنید

- کاتالوگ شش برنامه در نسخه اولیه **نمونه قابل ویرایش** است؛ وضعیت و توضیحات و صحت هر برنامه را بازبینی کنید.
- لینک فایل واقعی، نسخه، حجم فایل، مجوز استفاده و سیستم‌عامل را برای هر برنامه وارد کنید.
- ایمیل یا کانال تماس رسمی را مشخص کنید.
- متن حریم خصوصی را با شرایط واقعی سایت و سرویس‌های میزبانی هماهنگ کنید.
- برای دامنه اختصاصی مراحل خرید و DNS را به‌صورت جداگانه تکمیل کنید.
