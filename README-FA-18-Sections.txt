راهنمای فارسی

این نسخه صفحه اصلی سایت Rohani98 را به ۱۸ بخش بزرگ (۱۷ بخش صفحه + فوتر) تبدیل می‌کند.

ویژگی‌ها:
- صفحه اصلی سه‌بعدی با انیمیشن و افکت شیشه‌ای
- تبلیغات مستقل برای شرکت‌ها، فروشگاه‌ها، عمده‌فروشی‌ها، صرافی‌ها و دواخانه‌ها
- نمایش تعاملی ۵ نمونه تبلیغ حسابداری (اعداد نمایشی‌اند)
- تمام ۸ برنامه با عکس‌های معرفی و فیلتر انتشار / ویندوز / اندروید
- معرفی بنیان‌گذار، مراحل سفارش، امکانات، پرسش‌وپاسخ و فرم سفارش
- ظاهر واکنش‌گرا برای گوشی و کامپیوتر
- پیوند به contact.html برای سفارش؛ فرم قبلی تغییر نکرده است

فایل‌های اصلی جدید:
- index.html
- assets/css/home-ultimate.css
- assets/js/home-ultimate.js

بقیه فایل‌های همراه برای اطمینان از هماهنگی داده‌ها و عکس‌ها هستند.

روش بررسی:
۱. فایل ZIP را کامل استخراج کنید.
۲. فایل index.html را فقط از پوشه استخراج‌شده باز کنید (نه از داخل WinRAR).
۳. دکمه‌ها و تصاویر را بررسی کنید.
۴. پیش از قرار دادن روی GitHub از نسخه زنده پشتیبان بگیرید.

توجه: نماهای مالی مفهومی و تبلیغاتی‌اند؛ سیستم حسابداری سفارشی صرفاً پس از توافق ساخته می‌شود.
