ROHANI98 REIMAGINED — نسخه بازطراحی‌شده همه صفحات

این پروژه جایگزین کامل فایل‌های سایت اصلی است.

بخش‌های بازطراحی‌شده:
- صفحه اصلی با هویت بصری مستقل و لوگوی حجمی متحرک
- آرشیو نرم‌افزارها، جست‌وجو، فیلتر سیستم‌عامل و وضعیت دانلود
- صفحات اختصاصی RohaniOCR / RohaniScreenshot / InteractiveWallpaper
- صفحه جزئیات پویا برای بقیه نرم‌افزارها
- درباره ما، داستان استودیو و سازنده
- فرم سفارش با پیش‌نمایش زنده، ارسال واتساپ، اشتراک تلگرام و پیش‌نویس Gmail
- راهنمای نصب و پرسش‌های متداول
- حریم خصوصی و صفحه 404

فایل‌های CSS/JS جدید: assets/css/studio.css و assets/js/studio.js
فهرست نرم‌افزارها از assets/js/apps.js اصلی خوانده می‌شود؛ لینک‌های دانلود دست‌نخورده‌اند.

روش استفاده: پس از گرفتن نسخه پشتیبان، کل محتوای این پوشه را جایگزین محتوای مخزن GitHub Pages کنید؛ ساختار پوشه‌ها حفظ شود. هنگام آپلود باید فایل index.html در ریشه باشد.

ملاحظات:
- سایت ایستا است و فرم سفارش مستقیماً داده را روی سرور سایت ذخیره نمی‌کند.
- دکمه تلگرام صفحه اشتراک تلگرام را باز می‌کند، نه چت خصوصی یک مخاطب مشخص.
- نماهای تصویری صفحات محصول، شبیه‌سازی مفهومی هستند.
- حرکت‌های سنگین برای prefers-reduced-motion محدود شده‌اند.
