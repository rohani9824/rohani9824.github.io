درباره این سایت

Rohani98 یک وب‌سایت معرفی نرم‌افزارهای ویندوز و اندروید و ارائه راه ارتباطی برای سفارش نرم‌افزار اختصاصی است. این نسخه به‌صورت صفحات ایستای GitHub Pages ارائه می‌شود و حساب کاربری یا پرداخت آنلاین ندارد.

فرم سفارش و اطلاعات ارسالی

اطلاعاتی که در فرم سفارش وارد می‌کنید، در صفحه مرورگر شما برای پیش‌نمایش پیام استفاده می‌شود. تکمیل فرم به‌تنهایی اطلاعات را به سرور سایت ارسال نمی‌کند؛ پس از انتخاب واتساپ، تلگرام یا Gmail، شما ارسال پیام را تأیید می‌کنید. سرویس مقصد مطابق سیاست خود اطلاعات را پردازش می‌کند.

خدمات و پیوندهای خارجی

برای دانلود برنامه‌ها به GitHub Releases و برای ارتباط به سرویس‌هایی مانند WhatsApp، Telegram و Gmail پیوند داده می‌شود. این سرویس‌ها مستقل هستند و ممکن است اطلاعات فنی و داده‌های ارسالی را طبق شرایط خود پردازش کنند. قلمرو و نحوه پردازش آن‌ها تابع سیاست حریم خصوصی همان سرویس‌هاست.

داده‌های فنی و مرورگر

میزبان GitHub Pages و سرویس‌های مرتبط ممکن است به‌طور مستقل داده‌های فنی مانند آدرس IP یا اطلاعات درخواست را ثبت کنند. این سایت به‌صورت پیش‌فرض سامانه ثبت‌نام و پایگاه داده شخصی برای سفارش‌ها ندارد.

امنیت دانلود و سازگاری

فایل‌های نصب از پیوندهای انتشار رسمی معرفی می‌شوند. پیش از نصب، منبع فایل را بررسی کنید و نسخه متناسب با سیستم‌عامل خود را انتخاب نمایید. بعضی نسخه‌ها آزمایشی هستند؛ جزئیات آن‌ها در صفحه محصول مشخص شده است.
