بسته اصلاح گرافیک همه برنامه‌های Rohani98

اصلاحات:
- تصاویر واقعی فایل تصویر برای همه ۸ برنامه در پوشه assets/images/ قرار گرفت. تصاویر گرافیکی تبلیغاتی هستند، نه لزوماً عکس مستقیم از محیط برنامه.
- صفحه‌های اختصاصی RohaniOCR، RohaniScreenshot و InteractiveWallpaper به‌جای نماد CSS تصویر اختصاصی نشان می‌دهند.
- صفحه app.html?id=... تصویر برنامه را از کاتالوگ نشان می‌دهد (شامل TriCalendarPro و MaxPlayer).
- صفحه apps.html و کارت‌های صفحه اصلی هم تصویر دارند.
- نوشته دکمه «دانلود از GitHub Releases» به «دانلود نرم‌افزار» تغییر کرد؛ آدرس اصلی فایل‌ها بدون تغییر است.

برای آزمایش در کامپیوتر: ابتدا ZIP را Extract All کنید، سپس فایل index.html را باز کنید. باز کردن HTML از داخل WinRAR می‌تواند دسترسی تصاویر و فایل‌های css/js را قطع کند.

برای GitHub: محتویات پوشه استخراج‌شده را با ساختار پوشه‌ای مشابه در ریشه مخزن جایگزین کنید (فایل‌های assets/js/studio.js، assets/css/studio.css، صفحات محصول، و پوشه assets/images).

توجه: این بسته بر اساس نسخه Rohani98 REIMAGINED ساخته شده؛ اگر نسخه قدیمی سایت روی GitHub است، فایل‌های ZIP کامل را با حفظ مسیرها به‌روزرسانی کنید.
