راهنمای نسخه Rohani98 NEON GALAXY

این بسته یک وب‌سایت واقعی HTML/CSS/JavaScript است، نه تصویر ثابت.

محتوا:
- صفحه اصلی دارای ۲۰ بخش اصلی تبلیغاتی و معرفی خدمات
- داشبورد نمایشی حسابداری با دکمه‌های تعاملی و نمودار قابل تغییر
- انواع راهکارهای شرکت‌ها، فروشگاه‌ها، عمده‌فروشی‌ها، صرافی‌ها و دواخانه‌ها
- تصاویر ۸ برنامه، اطلاعات نسخه و لینک‌های واقعی دانلودِ برنامه‌های منتشرشده
- فرم سفارش موجود با ارسال از واتساپ، تلگرام و Gmail
- طراحی ریسپانسیو برای موبایل و کامپیوتر
- ذرات متحرک، نورپردازی، کارت‌های شیشه‌ای و عناصر سه‌بعدی

برای دیدن در کامپیوتر:
۱. فایل ZIP را Extract All کنید.
۲. از داخل پوشه استخراج‌شده، index.html را در Chrome باز کنید.
۳. توجه: فایل‌های HTML را مستقیماً از داخل WinRAR باز نکنید.

برای انتشار در GitHub Pages:
- همه محتویات بسته کامل جایگزین فایل‌های مخزن شوند، یا فقط فایل‌های موجود در بسته تغییرات به همان مسیرها منتقل شوند.
- پوشه assets و مسیرهای درون آن باید بدون تغییر اسم پوشه‌ها حفظ شوند.
- قبل از آپلود، از نسخه فعلی سایت پشتیبان داشته باشید.
